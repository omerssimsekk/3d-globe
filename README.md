# 3D Dünya Görselleştirme Projesi

Bu proje, [Three.js](https://threejs.org/) kütüphanesi kullanılarak oluşturulmuş, etkileşimli bir 3D dünya görselleştirmesi sunar. Dünya üzerinde belirlenen noktalar arasında uçuş rotaları animasyonları içerir.

## Temel Aldığı Proje

Bu çalışma, [hululuuuuu/GlobeStream3D](https://github.com/hululuuuuu/GlobeStream3D) projesi temel alınarak geliştirilmiştir.

## Kurulum

Projeyi yerel makinenizde kurmak için:

1.  Depoyu klonlayın: `git clone <repository_url>`
2.  Proje dizinine gidin: `cd <proje_dizini>`
3.  Gerekli bağımlılıkları yükleyin: `npm install`

## Çalıştırma

Geliştirme sunucusunu başlatmak için:

```bash
npm run dev
```

Uygulama varsayılan olarak `http://localhost:XXXX` adresinde çalışacaktır (port numarası terminalde belirtilir).
